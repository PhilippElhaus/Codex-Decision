# Codex Jev 0.6.1 release notes

The VS Code control 0.5.1 fixes a settings layout shift. The task relevance checkbox now keeps its label and help text in place when selected or cleared. The plugin hook and line filtering behavior are unchanged from 0.6.0.

This release includes the 0.6.0 Linux x86_64 plugin ZIP and the updated VSIX. Install the VSIX, update the version-pinned Codex composer patch, and reload VS Code manually.
