# Codex Jev 0.5 release notes

Search results now receive a third independent Noul probability: whether each match or path helps the current task. The optional relevance guard can only keep more lines; it starts in preview mode, with probabilities visible in the panel and private receipt. Locally protected lines are no longer sent as Jev targets, reducing request work. The hook still requires conservative omission and exact-text gates, retains diagnostics and unjudged lines, and returns the full result on a failed batch.

The Rust quality CLI now reports evidence loss by route and split and replays stricter line gates plus the search relevance guard against reviewed receipts. No settings change automatically. The Linux x86_64 plugin package contains a Rust executable and requires no Python at hook runtime. The paired VS Code control 0.4.0 shows five recent judged lines, the latest line's animated probability bars, keep reasons, and search relevance where applicable. Config schema 2 preserves existing selections and adds a disabled-by-default search policy. The composer patch remains a separate version-pinned local tool.
