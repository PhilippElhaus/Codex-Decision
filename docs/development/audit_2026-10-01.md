# Cleanup and integration audit, 2026-10-01

The live failure came from Windows-created WSL session folders with mode `755`.
The Rust hook requires private directories (`700`), so it exited before recording
activity. The control now applies Linux permissions through WSL UNC paths,
checks ownership without following links, and repairs existing session folders.
Configuration files use `600`. Cached inode checks avoid starting WSL processes
on every unchanged status poll.

Long turns exposed another integration defect: the last user task could fall
outside the 64 KiB transcript tail, preventing replacement. A bounded fallback
scan recovers the latest task and rejects oversized or sensitive user records.
Configuration failures now write session hook health. After one minute without
a receipt, the activity tooltip explains how to check hook execution.

Additional fixes and cleanup:

- Settings recover from missing replies and transport errors; late replies are ignored.
- Activity cursors survive atomic log compaction and same-file truncation without
  resetting this view's counters or replaying retained events.
- Legacy installation latency counts requests, including Choice checks.
- Monitor mode triggers layout recalculation. A cramped composer places the
  compact control above the toolbar instead of overlapping host buttons.
- Hook code is split into focused modules; unused types and policy methods are removed.
- WSL patch tests use deterministic bridge fixtures and run on Linux CI.
- Package builds check versions, executable Linux x86_64 ELF targets, exact file
  allowlists, and packaged source bytes. VSCE and Playwright versions are pinned.
- Unreferenced icon and composer-preview wrappers are removed.
- Superseded generated packages and duplicate staging/export files are removed.
  The current package pair and the two recent rollback pairs are retained.

The active Chime bridge and personal marketplace path remain supported because
both are used by this installation. Runtime logs, saved originals, plugin caches,
credentials, and composer rollback files are preserved.

Validation covers 54 Rust tests, Clippy, 39 Node tests, four Python tests, Chromium
and native Edge at four widths, and real Windows/WSL config creation. The real
terminal reached Jev after the directory repair. An isolated live 70/25 trial
shortened five of eight fixtures, kept all 224 required lines, and verified every
saved original byte for byte. The installed 95/5 cutoffs remain unchanged; their
replay omitted no lines on this corpus. Synthetic receipts are retained locally
under `.local/quality/verification-0.8.2/`.

Delivery consists of hook/plugin `0.8.2+codex.20261001130044`, control `0.7.7`, and
the pinned composer patch for Codex extension `26.928.31416`. The updated plugin
passes `jevctl check-hook-trust`. Reload VS Code to load the installed control
